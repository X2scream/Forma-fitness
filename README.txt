FORMA — เว็บเช็กลิสต์และติดตามการออกกำลังกาย

เปิดใช้งาน:
1. วิธีง่ายที่สุด: เปิดไฟล์ index.html ในเว็บเบราว์เซอร์ (แนะนำคอมพิวเตอร์)
2. หากใช้มือถือและอยากเก็บข้อมูลได้เสถียร ให้เผยแพร่โฟลเดอร์นี้บนเว็บ HTTPS เช่น GitHub Pages หรือ Netlify แล้วเปิดลิงก์ด้วย Safari/Chrome
3. เพิ่มเว็บไซต์ไว้ที่หน้าจอโฮมเพื่อใช้คล้ายแอป (Safari: Share > Add to Home Screen)

ความสามารถ:
- เช็กลิสต์ตารางฝึก 5 วัน (จันทร์ อังคาร พุธ ศุกร์ เสาร์) + 2 วันพัก
- เพิ่มเช็กลิสต์เฉพาะวัน และจดโน้ต
- บันทึกอาหารพร้อมแคลอรีและโปรตีน
- ตัวนับน้ำดื่ม +250/+500 มล. หรือกรอกจำนวนเอง
- ให้คะแนนพลังงานร่างกาย 1–5 ในแต่ละวัน
- บันทึกน้ำหนักพร้อมกราฟเปรียบเทียบเป้าหมาย 4 เดือน
- เปลี่ยนวันเพื่อดูข้อมูลย้อนหลัง
- แก้เป้าหมายในเมนูตั้งค่า
- สำรองและกู้คืนข้อมูลผ่านไฟล์ JSON

สำคัญ:
ข้อมูลถูกเก็บด้วย localStorage ภายในเบราว์เซอร์และโดเมนที่เปิดใช้ ไม่ใช่ระบบบัญชีหรือคลาวด์
เปิดผ่าน file:// หรือแอปดูไฟล์บนมือถือบางระบบอาจไม่เก็บข้อมูลถาวร
ควรใช้งานผ่าน HTTPS และส่งออกไฟล์ JSON สำรองเป็นประจำ
หากเปิดจากคนละโดเมนหรือคนละเบราว์เซอร์ ข้อมูลจะไม่ซิงก์อัตโนมัติ
แคลอรี 2250 โปรตีน 160 g น้ำ 2500 ml น้ำหนัก 86→75 kg เป็นค่าเริ่มต้นแก้ไขได้
